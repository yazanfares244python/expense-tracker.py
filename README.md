expense-tracker.py

What is this project about?

It's a CLI-based expense tracker app that allows users to manage their expenses, organize them by categories and dates, and view statistics about their spending.

How to use it or set it up?

When you start the program, you'll be presented with 10 menu options that allow you to add, view, edit, delete, search, and manage expenses. Your data will automatically be loaded from and saved to expense_tracker.json using JSON.

To run the program, execute the Python file using:


python expense_tracker.py

What are the features of this project?

The features of this project include using OOP by separating 3 classes according to their responsibilities, saving and loading expense data through JSON, adding and editing expenses with categories and dates, filtering expenses by category or date, searching for specific expenses, deleting individual expenses or clearing all records, displaying spending statistics such as the most expensive, cheapest, total, and average expenses, and validating user inputs and stored JSON data to maintain data consistency.
