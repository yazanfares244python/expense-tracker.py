What is the project about?

This project is about using a digital expense tracker where you can add, view, delete, edit, and manage expenses

How to use it / set it up?

Run it in a Python script

What are the features of the project?

It uses menu options so the user can choose what they want to do (add, view, delete, edit, search, etc.), uses a clean exit method, saves expense data using JSON, checks if expenses exist before performing specific operations, and includes realistic features like expense categories, amounts, prices, purchase dates, searching, category and date filtering, total money spent, total money spent by category, average expense, most expensive and cheapest expenses, and budget checking
